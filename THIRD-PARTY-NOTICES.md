# Third-party notices

## Earth Gravitational Model 1996 (EGM96)

The files in `GravityModelFiles` contain EGM96 model metadata and coefficients prepared for GeographicLib. The metadata identifies the National Geospatial-Intelligence Agency as publisher, model ID `EGM1996A`, and release date 1997-01-01. Runtime responses expose the model identity and a SHA-256 of the coefficient file for traceability.

## GeographicLib.NET

Gravity calculations use the `GeographicLib.NET` NuGet package, version 2.3.2. Refer to that package and upstream GeographicLib distribution for their applicable notices and licenses.
